# Credits

## Audio

All audio in POP.POP.Pistola is **procedurally synthesized at runtime with the Web Audio API**
(oscillators, filtered noise, Karplus-Strong plucked strings, formant filters and a generated
reverb impulse). No recorded samples ship with the game. See `src/audio/`.

### Sampled audio: none

The game currently contains no sampled audio. Any samples added in the future **must be CC0**
(public domain) and listed here with title, author, source URL and license.

Optional drop-in music files (`public/audio/music/`, see the README there) are supplied by
whoever deploys the game; they must also be listed here if committed to the repo.
